# notes — working docs (efímeras)

Todo lo que hay en esta carpeta **está fuera de git** (salvo este README) y **no sobrevive a la
tarea que lo generó**. Acá van los planes de implementación, análisis, auditorías, comparativas y
borradores — propios o generados por Claude Code.

Cuando la tarea termina, cada nota tiene **cuatro salidas y solo cuatro**:

| Qué era la nota | A dónde va |
|---|---|
| Una **decisión** con alternativas descartadas | un ADR nuevo en `docs/adr/` |
| Una **regla o instrucción** | se funde en un doc reference existente (no un archivo nuevo) |
| Un **análisis de un momento** | se congela en `docs/design/` |
| Ninguna de las anteriores | **se borra** — para eso está git |

Nada de esto es "por prolijidad": una nota que se queda dando vueltas se lee después como si
fuera doc vigente. Las reglas completas están en `../CLAUDE.md`, sección **Documentación**.
